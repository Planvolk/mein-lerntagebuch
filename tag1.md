# Tag 1 — Web Fundamentals: Daten, APIs & Software

**Was gelernt?**
Wie das Web technisch funktioniert: Request-Response-Zyklus, REST-APIs, JSON als Datenformat, API-Keys als Zugangskontrolle.

**Welches Problem?**
Ich wusste zwar, dass unsere Restaurant-Tools (Kasse, Dienstplan, Reservierung, Warenwirtschaft) "APIs haben", aber nicht wirklich, was das konkret bedeutet oder wie ich das für mein eigenes Projekt (die Schaltzentrale) nutzen könnte.

**Wie gelöst?**
Öffentliche API (Open-Meteo) selbst erkundet, einen echten Request abgesetzt und die JSON-Antwort Feld für Feld verstanden. Dabei gemerkt: Eine gute API-Doku macht den Unterschied — genau das werde ich später von den Anbietern unserer eigenen Tools einfordern.
