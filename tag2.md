# Tag 2 — Dateien, Projekte & die Kommandozeile

**Was gelernt?**
Wie man mit Claude Code ein Next.js-Projekt generiert, lokal mit `npm run dev` startet und Umgebungsvariablen sicher über eine `.env.local`-Datei handhabt, die nie ins Repository wandert.

**Welches Problem?**
Ich hatte Respekt vor der Kommandozeile — bisher lief bei mir alles über fertige Oberflächen (Kasse, Excel). Ein eigenes Projekt lokal zum Laufen zu bringen, wirkte wie eine hohe Hürde.

**Wie gelöst?**
Schritt für Schritt: Projekt generieren, Struktur anschauen, `.env.local.example` als Vorlage anlegen, `npm run dev` starten, im Browser auf localhost prüfen. Die Hürde war kleiner als gedacht — und genau dieses Muster (Vorlage → eigene Werte eintragen → lokal testen) brauche ich später auch für die echten API-Keys meiner Restaurant-Tools.
