# mein-lerntagebuch

7-Tage-Entwicklertagebuch zum Vibe Coding Bootcamp (Digitale-Leute), Modul M2.3 — Git & GitHub.

Jeder Eintrag (`tag1.md` bis `tag7.md`) beschreibt einen echten, eigenständigen Lernschritt aus der ersten Bootcamp-Woche: was gelernt wurde, welches Problem dahinterstand, und wie es gelöst wurde.

**Anmerkung:** Die sieben Einträge (`tag1.md`–`tag7.md`) wurden gesammelt nachgetragen statt strikt an sieben Kalendertagen einzeln committet, da ich mit den Abgaben in Verzug war. Die Inhalte selbst sind ehrlich und spiegeln reale, unterschiedliche Lernerfahrungen aus der ersten Bootcamp-Woche wider, nicht rückwirkend erfunden.
