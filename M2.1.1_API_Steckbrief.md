# API Steckbrief: Open-Meteo Weather Forecast API

## 1. Basis-Informationen
- **API Name:** Open-Meteo Weather Forecast API
- **Endpoint:** https://api.open-meteo.com/v1/forecast
- **Authentifizierung:** keine (Public / Open Access)
- **Kosten & Rate Limit:** kostenfrei für nicht-kommerzielle Nutzung (Fair Use)
- **Anwendungsfall im Projekt:** Wetter als zusätzliche externe Datenquelle für die Schaltzentrale. Für einen Restaurantbetrieb mit Außenbereich ist die Wettervorhersage direkt relevant.

## 2. Verwendeter Aufruf

GET https://api.open-meteo.com/v1/forecast
    ?latitude=49.99&longitude=8.25
    &daily=temperature_2m_max,precipitation_probability_max
    &timezone=Europe/Berlin&forecast_days=3

Query-Parameter:
- `latitude` / `longitude` — Koordinaten der Zielregion (hier Mainz)
- `daily` — welche Tageswerte geliefert werden sollen
- `timezone` — Zeitzone, nach der die Tagesgrenzen berechnet werden
- `forecast_days` — Anzahl der Vorhersagetage

## 3. JSON-Response (eigener Abruf am 15.09.2026)

{
  "latitude": 50.0,
  "longitude": 8.26,
  "utc_offset_seconds": 7200,
  "timezone": "Europe/Berlin",
  "timezone_abbreviation": "GMT+2",
  "elevation": 107.0,
  "daily_units": {
    "time": "iso8601",
    "temperature_2m_max": "°C",
    "precipitation_probability_max": "%"
  },
  "daily": {
    "time": ["2026-09-15", "2026-09-16", "2026-09-17"],
    "temperature_2m_max": [28.3, 22.7, 21.0],
    "precipitation_probability_max": [0, 25, 0]
  }
}

## 4. Was bedeuten die Felder?
- `daily.time` — die drei Tage, für die die Vorhersage gilt (ISO-8601)
- `daily.temperature_2m_max` — Höchsttemperatur des Tages in 2 m Höhe, in °C
- `daily.precipitation_probability_max` — höchste Niederschlagswahrscheinlichkeit des Tages, in %
- `daily_units` — liefert die Einheiten gleich mit, statt dass man sie erraten muss
- `latitude` / `longitude` — die Koordinaten, auf die Open-Meteo den Abruf gerastert hat: angefragt waren 49.99 / 8.25, zurück kommen 50.0 / 8.26
- `timezone` / `utc_offset_seconds` — Zeitzone und Versatz zu UTC (hier GMT+2, also 7200 Sekunden)
- `elevation` — Höhe des Ortes über NN in Metern, von der API automatisch ergänzt

## 5. Bonus: Code von Claude generiert

async function getWeatherData() {
  const url = "https://api.open-meteo.com/v1/forecast"
    + "?latitude=49.99&longitude=8.25"
    + "&daily=temperature_2m_max,precipitation_probability_max"
    + "&timezone=Europe/Berlin&forecast_days=3";

  const response = await fetch(url);
  const data = await response.json();

  data.daily.time.forEach((tag, i) => {
    console.log(
      `${tag}: bis ${data.daily.temperature_2m_max[i]}°C, ` +
      `Regenwahrscheinlichkeit ${data.daily.precipitation_probability_max[i]}%`
    );
  });
}
